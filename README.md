# Calorix AI 🍏

Calorix AI is a premium, AI-powered nutrition tracking web application. It allows users to log their meals using natural language and instantly receive accurate calorie estimations, macronutrient breakdowns, and personalized activity recommendations.

## Features
- **Natural Language Parsing:** Just type what you ate (e.g., "I had a chicken sandwich and an apple").
- **Hybrid AI Engine:** Powered by a robust integration of LLMs and the global OpenFoodFacts database.
- **Interactive Dashboard:** Beautiful weekly data visualizations built with Recharts.
- **Premium UI:** Glassmorphism, micro-animations, and a highly responsive design using Tailwind CSS and Next.js.

## Tech Stack
- **Frontend:** Next.js 16, React, Tailwind CSS, shadcn/ui, Recharts
- **Backend:** Node.js, Express, TypeScript, Google Gemini API
- **Database:** MongoDB

## Getting Started
1. Clone the repository
2. Run `npm install` in both `/frontend` and `/backend`
3. Add your environment variables in `/backend/.env`
4. Run `npm run dev` in both directories to start the development servers.
